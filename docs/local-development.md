# Local development

`make test` uses a fake backend solely for deterministic domain tests. The actual Docker backend is exercised by `make demo-api`, `make demo-agent-task`, `make demo-containment`, `make demo-security-real`, `make demo-timeout`, `make demo-cancel`, and `make demo-recovery`. It requires a locally built `agent-runtime-sandbox:local` image, created by `make build-sandbox`. Docker's runtime-default seccomp profile is used; the backend does not override it with a portable-profile name.

`make bootstrap-local` creates a kind cluster and deploys the hardened control-plane chart; `make smoke` verifies its readiness endpoint. Task sandbox execution remains a trusted local control-plane process calling Docker, not a claim that the kind pod has Docker access. `make demo-observability` starts the project-scoped OTel Collector, Jaeger, Prometheus, and Grafana stack. gVisor, Vault, SPIRE, and Firecracker are optional; do not install them merely to satisfy a demo. The local container mode is Level 1 only.
